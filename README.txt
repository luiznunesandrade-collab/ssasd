SABOR & PANELA v2

Recursos:
- Login e cadastro local
- Animações e transições
- Busca e filtros
- Favoritos
- Compartilhamento usando Web Share API; fallback para copiar link
- Avaliação de 1 a 5 estrelas
- Comentários nas receitas
- Ranking por avaliação
- Design responsivo

Abra index.html para testar.

IMPORTANTE:
O login e avaliações desta versão usam localStorage. É adequado para demonstração, não para autenticação real de um site público. Para produção, use backend, banco de dados e senhas armazenadas com hash seguro.
